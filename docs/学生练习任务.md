# 学生练习任务

建议先阅读主讲义，再按任务编号运行配套代码。每个任务都包含“观察—修改—解释”三个环节。不要只复制代码运行。

## 任务 1：环境与 Mat（对应 `00_first_program.cpp`）

1. 把画布尺寸从 640×360 改成 800×600。
2. 修改背景颜色和文字颜色，注意 OpenCV 彩色图像默认按 B、G、R 顺序传值。
3. 输出 `rows`、`cols`、`channels()`、`elemSize()`。
4. 解释 `CV_8UC3` 中 8U 和 C3 分别代表什么。

验收：能够创建 Mat、绘制文字、保存结果，并解释图像尺寸与数据类型。

## 任务 2：图片读写（对应 `01_image_io.cpp`）

1. 准备一张 JPG 图片，通过命令行参数传入程序。
2. 将读取模式改成 `IMREAD_GRAYSCALE`，比较通道数。
3. 分别保存为 JPG 和 PNG，比较文件大小与图像质量。
4. 故意输入错误路径，观察 `empty()` 检查的作用。

验收：能正确读取、检查、显示和保存图像。

## 任务 3：ROI 与内存共享（对应 `02_mat_roi.cpp`）

1. 调整 Rect 的 x、y、width、height。
2. 修改 `roi`，观察原图对应区域是否变化。
3. 修改 `roiCopy`，观察原图是否变化。
4. 打印原图和 ROI 的 `step[0]`、`cols * elemSize()`、`isContinuous()`。
5. 尝试创建“覆盖整行宽度”的 ROI，再比较连续性。

验收：能够解释浅拷贝、深拷贝、ROI、step 和连续性之间的关系。

## 任务 4：像素遍历（对应 `03_pixel_access.cpp`）

1. 将系数 1.2 改成 0.8，观察输出变化。
2. 分别注释 at、ptr、迭代器实现，确认剩余实现能独立运行。
3. 将输出改成 `CV_8UC1`，实现单通道处理。
4. 创建一个非连续 ROI，使用 `ptr(y)` 对它逐行处理。
5. 解释为什么不能对非连续 ROI 直接按 `total() * elemSize()` 做一次性 memcpy。

验收：三种遍历方式输出一致；能够正确处理 ROI 的行跨度。

## 任务 5：图像处理流程（对应 `04_imgproc_pipeline.cpp`）

1. 改变 GaussianBlur 的核大小和 sigma。
2. 比较均值滤波、中值滤波和高斯滤波。
3. 调整 threshold 的阈值。
4. 调整 Canny 的低、高阈值。
5. 将开运算改为闭运算，观察前景区域变化。
6. 增加 `findContours()`，绘制外轮廓并计算外接矩形。

验收：能解释每种处理操作的目的，并能通过参数改变结果。

## 任务 6：摄像头采集（对应 `05_videoio_camera.cpp`）

1. 将摄像头索引从 0 改为 1（存在第二个摄像头时）。
2. 输出摄像头的宽度、高度和 FPS 属性。
3. 尝试通过 `set()` 调整分辨率，观察设备是否接受。
4. 增加一个高斯滤波模式。
5. 将处理后的帧写入图片文件。

验收：能打开摄像头、读取帧、显示结果、释放资源。

## 任务 7：背景建模（对应 `06_video_mog2.cpp`）

1. 固定摄像头不动，观察背景模型逐渐稳定的过程。
2. 在画面中移动物体，观察前景掩码。
3. 调整 MOG2 的历史帧数、方差阈值或阴影检测参数。
4. 比较摄像头移动和固定时的效果。

验收：能够说明背景建模依赖时间信息，且对光照变化和摄像头运动敏感。

## 任务 8：特征点匹配（对应 `07_features2d_orb.cpp`）

1. 修改 ORB 最大特征点数量。
2. 修改第二张图像的平移量。
3. 输出匹配数量。
4. 取消 `crossCheck`，改用 KNN 匹配，并尝试 ratio test。
5. 解释 ORB 描述子为什么通常使用 Hamming 距离。

验收：能够完成特征点检测、描述和匹配，并解释匹配结果。

## 任务 9：相机几何（对应 `08_calib3d_pnp.cpp`）

1. 修改焦距和主点参数，重新投影观察二维坐标变化。
2. 修改合成的旋转和平移向量。
3. 比较真实位姿与 solvePnP 估计位姿。
4. 解释相机内参、外参、3D 点和 2D 点的关系。

验收：理解 solvePnP 的输入是 3D-2D 对应关系，以及内参和畸变参数的作用。

## 任务 10：DNN 推理（对应 `09_dnn_onnx.cpp`）

1. 准备一个可由当前 OpenCV DNN 版本支持的 ONNX 模型。
2. 阅读模型文档，确认输入尺寸、通道顺序、缩放系数和均值。
3. 修改 `blobFromImage()` 参数使其符合模型要求。
4. 打印输出张量的维度和尺寸。
5. 查阅模型输出定义，尝试解码模型结果。

验收：能够完成模型加载、预处理、前向推理，并说明输出后处理为什么依赖具体模型。

## 综合任务：实时图像处理工具（对应 `10_realtime_tool.cpp`）

必须实现：

- 打开摄像头并持续读取帧。
- 按 1/2/3/4 切换原图、灰度、高斯滤波和 Canny。
- 按 S 保存当前结果。
- 按 ESC 退出并释放资源。

拓展要求：

- 增加 HSV 颜色范围选择。
- 使用形态学操作清理掩码。
- 使用轮廓检测标记目标区域。
- 显示当前帧率 FPS。

验收标准：程序可连续运行，不因空帧、非法路径或用户退出导致异常退出；能够解释每个功能对应的 OpenCV 模块。
