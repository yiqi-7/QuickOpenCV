## 实现中容易踩的坑（都已在本分支修正）

| 位置 | 问题 | 正确写法 |
|---|---|---|
| `05_videoio_camera.cpp` | `waitKey(1) && 0xFF` 用逻辑与，结果只有 0/1 | `waitKey(1) & 0xFF` 按位与 |
| `07_features2d_orb.cpp` | `warpAffine` 覆盖了读入的第二张图 | 直接匹配 `box.png` 与 `box_in_scene.png` |
| `07_features2d_orb.cpp` | 仿射矩阵只给 5 个数，`m11` 写成 12 | 2×3 需要 6 个数，且对角线为 1 |
| `08_calib3d_pnp.cpp` | `std::vector<cv::Point2d>` 接 `projectPoints` 输出触发断言 | 必须用 `std::vector<cv::Point2f>` |
| `09_dnn_onnx.cpp` | `<<` 与 `?:` 优先级写错，Shape 输出粘连 | 给条件表达式加括号 |
| `10_realtime_tool.cpp` | 用了 `COLOR_BayerBG2BGR`，输入是三通道 | `COLOR_BGR2GRAY` |
| `10_realtime_tool.cpp` | `Canny(blurred, ...)` 但 `blurred` 从未赋值 | 先 `GaussianBlur(gray, blurred, ...)` |

## 构建与运行

```powershell
cd F:\CodingFile\opencv_cpp_quickstart
.\build.ps1                          # 编译全部
.\build.ps1 07_features2d_orb -Run   # 编译并运行某一课
.\build.ps1 -List                    # 列出全部目标
```

带命令行参数的程序（01/04/05/06/09/10）可以直接把参数跟在后面：

```powershell
.\build.ps1 09_dnn_onnx -Run assets\tiny_classifier.onnx assets\sample.jpg
```
